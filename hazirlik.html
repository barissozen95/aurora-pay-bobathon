Ön hazırlık

Atölye saatini kuruluma harcamamak için bu sayfadaki adımlar atölyeden en az iki iş günü önce tamamlanmalı. Kurumsal bilgisayarlarda kurulum izni, vekil sunucu ve erişim onayları beklenenden uzun sürer.

Hazır olduğunuzu nasıl anlarsınız? Repoda ./verify/run.sh m0 yedi kontrolün yedisinde PASS veriyor ve bob run API anahtarı hatası vermiyorsa hazırsınız.

Katılımcı için altı adım

1 · Bob IDE

2 · Bob Shell

Bob Shell, IDE ile birlikte gelmez; ayrı kurulur. Kurulum npm ile yapılır, bu yüzden Node.js ve registry.npmjs.org erişimi gerekir. Güncel kurulum komutu için Bob dokümantasyonuna bakın.

3 · Bob API anahtarı

bob run komutu etkileşimsiz çalıştığı için API anahtarı ister. Anahtar yoksa Görev 2 ve Görev 7 şu hatayla durur: Error: Bob API key is required. Set BOB_API_KEY environment variable.

Anahtar bir sırdırAnahtarı repoya, sohbet mesajına veya ekran paylaşımına koymayın. Atölyeden sonra portaldan iptal edebilirsiniz.

4 · Python ve git

Python 3.10 destek süresini doldurdu. Kurum güvenlik politikaları ve Bob'un kendisi desteği bitmiş sürümleri kurmayı reddeder; güncel bir sürüm kullanın.

5 · GitHub

Yeni kurulmuş bir Bob'da GitHub oturumu açık değildir ve oturum olmadan özel (private) repo klonlanamaz.

6 · Repo kurulumu ve son kontrol

git clone https://github.com/<kullanıcı-adınız>/<repo-adı>.git
cd <repo-adı>
./setup.sh --scanners
./verify/run.sh m0

python3 eski bir sürümü gösteriyorsa güncel Python'un yolunu verin:

PYTHON=/yol/python3.12 ./setup.sh --scanners

Kurum BT ekibi için

Atölye katılımcıların kendi kurumsal bilgisayarlarında ve kurum ağında yapılacaksa aşağıdaki gereksinimler önceden karşılanmalıdır.

Bob'un model ve servis uç noktaları için kurumunuza özel ek adresler gerekebilir; güncel listeyi IBM ekibinden isteyin. TLS denetimi (SSL inspection) yapan vekil sunucularda kurum kök sertifikasının git, pip ve npm tarafından tanınması gerekir.

Bilgisayar ve yetki

  • Bob IDE, Node.js, Python 3.11+ ve git kurabilecek yetki ya da bu araçların önceden kurulmuş olması.
  • Kullanıcı klasöründe sanal ortam oluşturma ve yerel Python betiği çalıştırma izni. Uç nokta koruma yazılımları .venv altındaki çalıştırılabilir dosyaları engelleyebilir.
  • Bash veya zsh içeren bir terminal. Repo betikleri (setup.sh, verify/run.sh, scripts/scan.sh) bash betikleridir; Windows'ta WSL kullanılması önerilir.
  • GitHub'da kişisel hesapla repo oluşturma kurum politikasına aykırıysa, atölye için ayrılmış bir GitHub organizasyonu kullanılmalıdır.

Lisans ve bakiye

  • Her katılımcı için Bob erişimi ve yeterli Bobcoin bakiyesi. Deneme oturumunda bir kişinin günlük harcaması yaklaşık 20 Bobcoin oldu (aynı gün yapılan başka işleri de içerebilir); katılımcı başına en az 25 Bobcoin ayırmak güvenli bir başlangıçtır.
  • M5'teki Findings paneli DevSecOps paketi gerektirir. Paket yoksa görev ./scripts/scan.sh ile aynı şekilde tamamlanır.
  • M7'deki yönetim portalı ve Bobalytics için yetki gerekir. Yetki yoksa eğitmen kendi ekranını paylaşır.

Yedek plan

Kurulum izinleri veya ağ erişimi zamanında çözülemiyorsa en güvenilir çözüm, araçları önceden kurulmuş hazır ortamlardır (sanal makine veya bulut geliştirme ortamı). Atölye günü için ayrıca misafir ağı ya da mobil bağlantı hazır tutulmalıdır.
